# FocusTrack — Privacy Policy

Public privacy policy for the **FocusTrack** Android app (`com.focustrack.app`),
published for the Google Play Store listing.

Live page: https://tirthdoshi009.github.io/FocusTrackPrivacyPolicy/

The app source lives in a separate repository. FocusTrack requests no `INTERNET`
permission and contains no analytics or third-party SDKs, so all usage data stays
on the device.
